## Como explorar

Comece por **cadastro → busca → estoque → vendas e cancelamento**. A importação
oferece outro caminho para adicionar peças. Use o menu do protótipo para trocar de
grupo e manter os dados da sessão.

As alterações duram apenas enquanto a página estiver aberta. Recarregar a página
ou usar **Reiniciar demonstração** restaura os exemplos iniciais.

## Avaliação

<span id="registro-sugerido-para-a-issue-ou-ata"></span>

O [guia de avaliação](avaliacao.md) reúne a sequência sugerida e o modelo de registro
das observações. Os roteiros de cada grupo detalham as tarefas e os cenários.
